# Supportive Service Locations WFL1 · Council District

The City of Syracuse Common Council District geographic dataset was created by the Syracuse-Onondaga County Planning Agency (SOCPA) for use in its GIS database. The shapefile consists of polygon features representing each of the five Common Council Districts in the City of Syracuse, as determined by the Onondaga County Board of Elections (BOE). This dataset was created directly from the Onondaga County Election District shapefile by using the "dissolve" command (applied to the CITY_CC attribute) in ArcMap. The only attribute included with this file is a single-character attribute identifying the district number. Updated 2010.
