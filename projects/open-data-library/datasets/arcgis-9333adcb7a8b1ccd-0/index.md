# Syracuse Zip Codes Map (2022)

Map of Zip Code boundaries within the City of Syracuse is from Syracuse Onondaga County Planning Agency (SOCPA) and was last revised in 2017. Due to an increase in population or to the improve postal operations, the US Postal Service® will occasionally add a new ZIP Code or change ZIP Code boundaries. This map of Zipcode boundaries within the City of Syracuse boundaries is accurate as of 2/2022. The five digits of a ZIP code (e.g.,12345) may be grouped as follows: [123] : Sectional Center or Large City [45] : Post Office facility or Delivery Area More information regarding this can be found at: https://faq.usps.com/s/article/ZIP-Code-The-Basics Data Dictionary: Label Definition Zip The zipcode for the area on the map. Name The name assigned to the zipcode. Zip_Name The zipcode for the area on the map. Shape__Area The area of the zipcode's polygon, automatically generated by ArcGIS. Shape__Length The length of the zipcode's polygon, automatically generated by ArcGIS.
