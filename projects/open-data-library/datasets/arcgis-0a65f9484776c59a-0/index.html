Data Dictionary: Label Definition print_key Abbreviated tax identification number (section-block-lot) parcel_location_address The parcel address of the property. prop_class The number of property class that this property falls within. own_owner_name The primary owners first and last name (or the name of the LLC or agency that owns the property). own_attention_to The person or role that the assessment is addressed to. own_po_box The P.O. box of the owner, if applicable own_street_address The property owner's street address. own_city_state_zip The property owner's city, state, and zip code. sch_taxable The taxable value of the property according to the local school district. muni_taxable The taxable value of the property according to the local municipality (City of Syracuse). cnty_taxable The taxable value of the property according to the local county (Onondaga County). total_av The taxable value of the property according to the Assessment Department.
