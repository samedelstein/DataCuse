Onondaga County Parcel File Metadata:Identification_Information:Citation:Citation_Information:Originator: Onondaga County Finance Department, Division ofReal Property Tax Services, Tax Mapping ProgramPublication_Date: Unpublished MaterialTitle: Onondaga County Parcel FileGeospatial_Data_Presentation_Form: vector digital dataDescription:Abstract:The Onondaga County Parcel file is intended to be used fordisplaying and analyzing cadastral data in a GIS environment. Thisdataset uses polygon features to represent all official tax parcelslocated within the county. The original dataset was digitized undercontract by the Onondaga County Water Authority (OCWA) frompaper tax maps in 1995. From 1996 to 2024, the parcel file wasupdated and maintained in CAD format by the Onondaga CountyFinance Department, Division of Real Property Tax Services, TaxMapping Program (Tax Mapping). Tax Mapping provided this dataannually to the Onondaga County Department of Planning(OCDOP) to convert to Environmental Systems Research Institute(ESRI) format for use in the county’s GIS. In 2024, the county’sparcel and tax mapping data was migrated from CAD to ESRIformat and is now maintained by Tax Mapping in an ESRIenvironment.Real Property information can be incorporated into the parcel filethrough use of a 26 character Tax ID attribute. Parcels withcondominiums are included in this dataset as a series of parcelsoverlain one-on-top of each other. As such, a point in polygonquery will return multiple records for these parcels.Purpose:Suitable for use in a GIS database for the display, analysis, query,and development of cadastral information for general planningpurposes.Supplemental_Information:The parcel data is derived from non-survey grade map sources thatwere not intended for conveyance.
