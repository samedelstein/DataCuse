Full publisher description

The Division of Code Enforcement maintains the Housing and Property codes and enforces compliance with the Syracuse Zoning Ordinance, among other tasks. Code enforcement ensures that structures are maintained in such a way so that they are safe to live in and that the property meets specific standards. When a structure is not in compliance with the code, it can be cited for a violation. The data here lists all of the code violations that have occurred from 2017 to the present. When a violation is issued, the owner has a set of time to bring the structure into compliance. Cases remain open until the violation is fixed. Sometimes, the case can be referred to the law department and the issue is resolved in court. For more on the Division of Code Enforcement, click here to view their webpage .
