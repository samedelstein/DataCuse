# Rezone Syracuse Parcels2026 2026 09 08 Public

Parcels (2026 parcel base file from Onondaga County Planning) with Rezone attributes. This data set was created by joining the 2024 rezone designation shapefile (Zoning Districts\Rezone_Syracuse_Parcels2024_2024-12-17_Public.shp) to the 2026 parcel basefile (ParcelBasefile_2026_Syracuse.shp) based on the field "TAXID." Any unmatched records, i.e. new parcels since 2024 as a result of lot alterations and/or new parcels coming online were identified by missing values in the REZONE field. The Rezone attributes for these unmatched parcels were populated using the underlying 2024 rezone designation where available, for instance if 3 parcels zoned R1 were merged into one parcel the designation of the new singular lot stayed R1. The same principle was applied for lot divisions where the underlying rezone attribute were uniform. Parcels with changes 2024-2026 can be identified using the NOTES field where any value indicates "Lot change - Rezone attribute did not carry over from 2024 to 2026 layer by Tax ID."In addition, zoning designations were updated based on any approved Zone Change projects in IPS (except in instances where the zone change needs to be applied post-resub and the spatial file doesn't yet reflect the resub). These parcels can be identified using the field "IPS_PRJ_ID," which indicates the project identifier of the zone change project in IPS.Note that 5 parcel resubdivisions resulted in (list below) split zoning districts.
