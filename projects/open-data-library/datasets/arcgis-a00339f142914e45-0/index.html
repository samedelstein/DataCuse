Full publisher description

Parcels (2026 parcel base file from Onondaga County Planning) with Rezone attributes. This data set was created by joining the 2024 rezone designation shapefile (Zoning Districts\Rezone_Syracuse_Parcels2024_2024-12-17_Public.shp) to the 2026 parcel basefile (ParcelBasefile_2026_Syracuse.shp) based on the field "TAXID." Any unmatched records, i.e. new parcels since 2024 as a result of lot alterations and/or new parcels coming online were identified by missing values in the REZONE field. The Rezone attributes for these unmatched parcels were populated using the underlying 2024 rezone designation where available, for instance if 3 parcels zoned R1 were merged into one parcel the designation of the new singular lot stayed R1. The same principle was applied for lot divisions where the underlying rezone attribute were uniform. Parcels with changes 2024-2026 can be identified using the NOTES field where any value indicates "Lot change - Rezone attribute did not carry over from 2024 to 2026 layer by Tax ID."In addition, zoning designations were updated based on any approved Zone Change projects in IPS (except in instances where the zone change needs to be applied post-resub and the spatial file doesn't yet reflect the resub). These parcels can be identified using the field "IPS_PRJ_ID," which indicates the project identifier of the zone change project in IPS.Note that 5 parcel resubdivisions resulted in (list below) split zoning districts. These were assigned the attribute "Pending" to indicate that their zoning designation is pending approval and adoption (these are in addition to one "Pending" parcel carried over from the 2024 data set - 030.-05-02.1 | 546-48 Burnet Ave & Crouse Ave N):097.-09-16.1 | 201 Kellogg St & Congress Ave097.-09-18.1 | 202 Holland St097.-09-20.1 | 212 Holland St103.-27-04.0 | 201 Montgomery St & Washington St E075.-04-12.0 | 635 Lafayette Ave W To Newell St W030.-05-02.1 | 546-48 Burnet Ave & Crouse Ave NOther changes include renaming any "IN" rezone attributes as "LI" to conform to how the Light Industry & Employment zone district is abbreviated within the zoning ordinance as well as the addition of the field "ZONE_LABEL" to facilitate zone district labeling on maps (values correspond to REZONE field).---The 2026 Onondaga County parcel file representing all tax parcels in the City of Syracuse as of August 2026. This data set was created by extracting all city parcels (those beginning with TAX_ID "3115") from the Onondaga County parcel base file (ParcelBasefile_2026_OnondagaCounty.shp).The source data set was shared via email by Ed Hart, GIS Program Manager, Onondaga County Department of Planning <edwardhart@ongov.net>on August 13, 2026. Detailed metadata from the county provided in the Description section, and also in the PDF here: Onondaga County Parcel File - 2026 with RPS.pdf. Two fields of "double" type were added and geometry calculated as follows: "LATITUDE" for the central point y-coordinate and "LONGITUDE" for the central x-coordinate both in decimal degrees. ---Source metadata:Onondaga County Parcel FileMetadata: The Onondaga County Parcel file is intended to be used for displaying and analyzing cadastral data in a GIS environment. This dataset uses polygon features to represent all official tax parcels located within the county. The original dataset was digitized under contract by the Onondaga County Water Authority (OCWA) from paper tax maps in 1995. From 1996 to 2024, the parcel file was updated and maintained in CAD format by the Onondaga County Finance Department, Division of Real Property Tax Services, Tax Mapping Program (Tax Mapping). Tax Mapping provided this data annually to the Onondaga County Department of Planning (OCDOP) to convert to Environmental Systems Research Institute (ESRI) format for use in the county’s GIS. In 2024, the county’s parcel and tax mapping data was migrated from CAD to ESRI format and is now maintained by Tax Mapping in an ESRI environment.Real Property information can be incorporated into the parcel file through use of a 26-character Tax ID attribute. Parcels with condominiums are included in this dataset as a series of parcels overlain one-on-top of each other. As such, a point in polygon query will return multiple records for these parcels.Purpose: Suitable for use in a GIS database for the display, analysis, query, and development of cadastral information for general planning purposes.Supplemental_Information: The parcel data is derived from non-survey grade map sources that were not intended for conveyance. This dataset should be used for general planning purposes only and not to determine property boundaries.
