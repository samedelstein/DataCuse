Full publisher description

This dataset details the results of water tests conducted in Skaneateles Lake related to blue-gree algae blooms and their potential affect of the city's water system. This dataset will continue to be updated with subsequent tests as they are available. Data Dictionary: Label Definition DATE Date the test was conducted on. SAMPLE LOCATION Location of the sample that the test was conducted on. Test Type Type of test conducted on the sample Detection Result Result of the test conducted. Dataset Contact Information: Organization: City of Syracuse Position: Data Program Manager Email: opendata@syr.gov City: Syracuse, NY
