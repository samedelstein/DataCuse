# Syracuse Bike Infrastructure (2023)

Included in the Syracuse Bike Infrastructure dataset are roads with designated bike lanes, bikeways, trails, or sharrows. Users should not consider this list exhaustive, as bicycle infrastructure may have been installed since the most recent update of this dataset. Additionally, some portions of trails included in this dataset are outside the City limits. This data is a previous dataset from 2023. For the current bike infrastructure, plese refer to the bike infrastructure dataset for the most recent year.
