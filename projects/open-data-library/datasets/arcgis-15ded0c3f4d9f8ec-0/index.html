Full publisher description

This list is updated and maintained by Syracuse's Landmark Preservation Board. Data Dictionary: Label Definition Definition Source SBL Section Block Lot Number (SBL). This is the unique identifier for that Parcel. Syracuse Landmark Preservation Board Property_Address The address of the property or district that is a locally protected site or district. These are parcel addresses not mailing addresses. Syracuse Landmark Preservation Board Zip The Zip code of the property or district that is a locally protected site or district. Syracuse Landmark Preservation Board LPSS Locally Protected Site. This wil either be listed as "Local Protected Site or Local District", "Eligible/Architecturally Significant", or will be empty. Syracuse Landmark Preservation Board NR_Eligible This states whether the property is eligible to be on the National Registry for Historica Places or if it is listed. The possible values are "NR Listed" - Is listed on the registry, "NR Eligible (SHPO)" - Is eligibel to be listed on the State Historic Preservation Office, or an empty field which means that the property is neither of those. Syracuse Landmark Preservation Board Latitude The latitude where the property or district is located at. Syracuse Landmark Preservation Board Longitude The longitude where the property or district is located at.
