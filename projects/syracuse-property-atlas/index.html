Method

Open data first, AI second.

The database starts with Syracuse parcels and enriches each selected property with vacant, rental registry, code violation, and unfit-property feeds. Census geocoding adds tract-level ACS context, OpenStreetMap adds nearby mapped features, and optional image analysis adds a visible-condition read when a free or paid image source is configured.

  • Parcel feed: 2025 Syracuse parcel map from data.syr.gov ArcGIS.
  • Open-data joins use parcel IDs, normalized addresses, and nearby coordinates.
  • ACS source: Census API, defaulting to the 2024 ACS 5-year profile.
  • OSM source: Overpass API, queried with an identifying User-Agent by the Python runtime.
  • AI output is intentionally cautious and limited to exterior conditions visible from the configured image source.
